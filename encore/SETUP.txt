APEX KARTS 3.0 - DRIVING VERSION - INSTALL (2 steps)

STEP 1. Put the new game online (GitHub)
   Open this link:  https://github.com/YDTSCHOOL/PORTAL/upload/main/encore
   Drag in ONLY the file index.html (from this folder). Click the green "Commit changes".
   Wait 2 minutes, then open the game in an incognito window (Ctrl + Shift + N).

STEP 2. Turn on the teacher race settings (Supabase, one time)
   Open the SCHOOL project in Supabase > SQL Editor > New query.
   Open race-settings.sql, copy everything, paste, and click Run.
   (Skip this and the game still works. Every student just gets the starting settings.)

TEACHER SETTINGS (Teacher view, at the bottom of the sign-in page)
   For each student: challenges per pit stop (1-3), laps per race (2-6),
   lap length (short / medium / long), driving help (on / off), coin run bonus (on / off).
   It shows an estimated "math share". Starting point: 1 per pit stop, medium laps = about half.
   Changes take effect the next time he signs in.

HOW THE GAME WORKS NOW
   Before each race: a qualifying challenge decides where he starts.
   He drives every lap himself. Each lap ends in a pit stop with a challenge (or more).
   The race waits while he thinks. First-try answers = the fastest stop + nitro.
   Race types: Grand Prix, Knockout, Time trial. Rivals: Rookie, Pro, Champion (level 4).
   A short "How to race" tutorial plays before his first race. It's also under How to play.

Shlomo's level, skills, stars, cash and parts all carry over. setup.sql does NOT need to be run again.
