SKETCHBOOK: 20 UNITS, 100 ASSIGNMENTS

WHO CAN SIGN IN
  Only students you add. Sketchbook uses the PORTAL's student list: one name and one 4-digit
  code work for both the portal and Sketchbook. A student can open Sketchbook only if
  "Sketchbook" is ticked in their programs. Anyone else sees "Ask your teacher to sign you up."

THE TEACHER PASSWORD
  Both Teacher pages (the portal's and Sketchbook's) use the portal's teacher password.
  It is stored as a hash inside Supabase. It is NOT in config.js (config.js is public).

ADD, REMOVE, OR SET A NEW CODE
  Either place works:
  - Portal:     https://ydtschool.github.io/PORTAL/#teacher  > Students tab
  - Sketchbook: https://ydtschool.github.io/PORTAL/sketchbook/  > "Teacher page" at the bottom
  "Add a student": first name, last name, 4-digit code, and the programs they can use.
  "Set a new code" also unlocks a student who typed the wrong code 5 times.
  "Remove student" stops them signing in. Their saved Sketchbook work stays in the database.

THE DATABASE (one time, already done if Sketchbook works)
  - supabase.com > SCHOOL project > SQL Editor > New query.
  - Paste everything from setup.sql (in this folder) and press Run. It is safe to run again.
  - It locks the student tables (Row Level Security, no direct access for the public key),
    adds the sign-in and save functions, and moves existing Sketchbook students onto the
    portal list with the same code they already used.

HOW A STUDENT SIGNS IN AND OUT
  She types her name and code. Her saved progress loads from the database, and her work
  saves after every question. "Sign out" saves everything and shows "Saved!".
  The same name and code work on any computer.

TO PLACE HER AHEAD
  Sketchbook Teacher page > her name > "Open the next unit". Each press opens one more unit.

EMAIL REPORTS
  Reports go to the address in config.js each time she signs out or closes the page.
  The first email from FormSubmit has an "Activate" button. Click it once (check Spam).

TO UPDATE LATER
  Upload the new files into the same sketchbook folder on GitHub. Her progress is kept.
